# 🚀 DevHub & Micro-Tools Suite

An ultra-fast, modern, client-side developer utility hub and resource directory built with pure JavaScript and Tailwind CSS. Designed for full-stack developers, frontend engineers, and open-source enthusiasts.

![DevHub Banner](https://images.unsplash.com/photo-1555066931-4365d14bab8c?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

- **🔒 100% Client-Side & Privacy First:** No data leaves your browser. All processing, encoding, and formatting happen locally.
- **⚡ Ultra-Fast & Lightweight:** Zero heavy JavaScript dependencies or framework overhead.
- **🎨 Glassmorphic Dark UI:** Modern, clean, responsive UI built with Tailwind CSS.
- **🔍 Global Search Bar:** Live search with shortcut support (`/` to focus, `Esc` to clear) across all tools and cheat sheets.
- **📱 Fully Responsive:** Seamless experience across desktop, tablet, and mobile screens.

---

## 🛠️ Micro-Tools Included

1. **JSON Formatter & Validator:** Format, beautify, validate, or minify JSON data instantly.
2. **Live Markdown Previewer:** Real-time Markdown compiler with styled HTML rendering.
3. **Base64 Encoder / Decoder:** Easily convert strings to and from Base64 format.
4. **Live Regex Tester:** Test regular expressions with real-time match highlighting and flag toggles (`g`, `i`).
5. **CSS Gradient Generator:** Interactive UI to generate CSS linear gradients with instant preview and copy options.
6. **Box Shadow Generator:** Custom UI for fine-tuning CSS box-shadow properties (`blur`, `spread`, `color`).
7. **URL Component Encoder / Decoder:** Safe URL encoding and decoding for web query parameters.

## 📚 Cheat Sheets & Guides
